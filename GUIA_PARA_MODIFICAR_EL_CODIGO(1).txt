NUTRIUIN - GUÍA PARA ENTENDER Y MODIFICAR EL CÓDIGO
=======================================================

1. QUÉ LENGUAJE HACE CADA COSA
------------------------------
HTML (.html)
Crea la estructura visible: títulos, botones, formularios, tarjetas y contenedores.

CSS (.css)
Da diseño al HTML: colores, tamaños, posiciones, animaciones, gráfica y ventana modal.

JavaScript (.js)
Da funcionamiento: cálculos, clics, búsqueda, almacenamiento, gráfica dinámica y PDF.

Librería externa jsPDF
Es código JavaScript ya creado por otra herramienta. menus.html lo carga desde internet y menus.js lo usa para construir el PDF.

2. MAPA DE CONEXIONES ENTRE ARCHIVOS
------------------------------------
index.html
  -> estilos.css  (diseño de la portada)
  -> login.js     (botones de navegación)

mvp.html
  -> mvp.css      (diseño de la calculadora)
  -> login.js     (IMC, metabolismo y calorías)

login.js
  -> localStorage (guarda nombre, calorías, objetivo y datos del usuario)

menus.html
  -> menus.css    (diseño del menú y del modal)
  -> jsPDF        (librería externa para PDF)
  -> alimentos.js (base de datos local)
  -> menus.js     (lógica completa del menú)

alimentos.js
  -> crea la variable global alimentos

menus.js
  -> lee alimentos
  -> lee localStorage
  -> modifica menus.html
  -> activa clases de menus.css
  -> usa jsPDF para crear el PDF

3. DATOS QUE PASAN DE UNA PÁGINA A OTRA
---------------------------------------
El proyecto usa localStorage, que es almacenamiento dentro del navegador.
login.js guarda los datos y menus.js los recupera.

Ejemplo:
localStorage.setItem("caloriasDia", valor);  -> guarda
localStorage.getItem("caloriasDia");        -> recupera

Si cambias la palabra "caloriasDia" en un archivo, también debes cambiarla en el otro.

4. REGLA MUY IMPORTANTE SOBRE id Y class
----------------------------------------
Un id del HTML puede ser buscado por JavaScript.
Ejemplo:
HTML:       id="modalExceso"
JavaScript: document.getElementById("modalExceso")

Una class del HTML puede ser diseñada por CSS o activada por JavaScript.
Ejemplo:
CSS:        .activo
JavaScript: classList.add("activo")

Si cambias un nombre, búscalo en TODO el proyecto para cambiar todas sus conexiones.

5. ORDEN IMPORTANTE DE LOS SCRIPTS
----------------------------------
En menus.html el orden debe seguir así:
1. jsPDF
2. alimentos.js
3. menus.js

menus.js usa la variable alimentos. Si menus.js se carga primero, aparecerá un error porque la variable todavía no existe.

6. CÓMO CAMBIAR COSAS COMUNES
-----------------------------
Cambiar colores:
Abre el archivo CSS de la página correspondiente.

Cambiar texto visible:
Busca el texto en el archivo HTML. Algunos textos dinámicos están en JavaScript.

Agregar un alimento:
Abre alimentos.js y copia la estructura de un objeto existente. Conserva las propiedades:
categoria, alimento, cantidad, unidad, kcal y grupo.

Cambiar el mensaje de exceso de calorías:
Texto visible: menus.html
Datos dinámicos y condición: menus.js
Diseño de la ventana: menus.css

Cambiar el contenido del PDF:
Busca la función construirReportePDF() en menus.js.

7. QUÉ NO TIENE ESTE PROYECTO ACTUALMENTE
-----------------------------------------
No está conectado a PHP, MySQL ni otra base de datos de servidor.
Los datos del usuario y su menú se guardan localmente en el navegador mediante localStorage.
La lista de alimentos está escrita directamente en alimentos.js.

8. ARCHIVOS PRINCIPALES
-----------------------

CAMBIO NUEVO: CATEGORÍA CEREALES SIN GRASA
------------------------------------------
La nueva tarjeta está en menus.html y llama a:

mostrarCategoria("Cereales sin grasa")

menus.js usa ese texto para filtrar los objetos de alimentos.js cuya propiedad categoria es:

"Cereales sin grasa"

Los 352 registros de esa categoría se copiaron de la hoja "Cereales sin grasa" de Libro1.xlsx.

COLUMNAS DE LAS TABLAS
----------------------
La función pintarTabla() de menus.js decide qué columnas mostrar:
- Frutas y verduras: Alimento, Cantidad, Unidad, Kcal, Grupo y Seleccionar.
- Todas las demás categorías: Alimento, Cantidad, Unidad, Kcal y Seleccionar.

El botón sigue diciendo "Agregar". El encabezado de su columna ahora dice "Seleccionar".

PLACEHOLDER DE ACTIVIDAD FÍSICA
-------------------------------
Un elemento <select> no admite placeholder real como un <input>. Por eso mvp.html usa una primera opción con:

selected disabled

Así el texto "Actividad física" aparece como guía, pero el usuario debe seleccionar una actividad válida antes de calcular.

RELACIÓN ENTRE EXCEL Y JAVASCRIPT
--------------------------------
Libro1.xlsx está incluido como fuente de consulta, pero el navegador no lo lee directamente.
La información que usa la página está convertida dentro de alimentos.js.

Flujo de datos:

Libro1.xlsx (fuente original)
        ↓ conversión de datos
alimentos.js (datos que sí lee el navegador)
        ↓
menus.js (filtra y dibuja la tabla)
        ↓
menus.html (muestra los resultados al usuario)

Por eso, cambiar una celda en Libro1.xlsx no cambia automáticamente la página.


ACTUALIZACIÓN DE LAS TABLAS DESDE EXCEL
---------------------------------------
Las tarjetas de menus.html corresponden a las ocho hojas de Tablas_Alimentos_Con_Precios.xlsx.
menus.js muestra en todas las tablas estas columnas:
Alimento | Cantidad sugerida | Unidad | Peso bruto (g) | Energía (kcal) | Precio por 100 g (MXN) | Seleccionar.

Para cambiar los datos de manera permanente, actualiza el Excel y vuelve a generar alimentos.js; no mezcles manualmente categorías antiguas como Carnes o Pescados.
